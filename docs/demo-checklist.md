# MVP 演示检查清单

## 普通用户流程

1. 打开 `frontend/index.html`，身份选择“普通用户”。
2. 进入“酸茶科普”，展示酸茶来源与制作技艺。
3. 进入“H5互动”，完成三步选择并生成专属配方。
4. 点击“生成海报与核销码”，跳转预约页。
5. 提交酸茶工坊预约。
6. 进入“酸茶商城”，添加商品到购物车。
7. 提交订单并完成模拟支付。
8. 在“工作台”查看订单、预约、海报。

## 商家流程

1. 身份切换为“商家”。
2. 进入“工作台”，查看销售额、订单数、售后单。
3. 发布一个新的酸茶商品，确认状态为“待审核”。
4. 对已支付订单点击“发货”。
5. 对售后单点击“处理完成”。

## 管理员流程

1. 身份切换为“管理员”。
2. 查看平台商品、订单、交易额、预约数据。
3. 审核待审核商家。
4. 审核商家新提交的商品。
5. 对预约记录点击“核销”。
6. 新增一条酸茶科普内容。

## 讲解重点

- 平台定位：德昂族酸茶非遗科普、互动体验与电商转化平台。
- 三类身份：普通用户、商家、管理员。
- 核心闭环：科普认知 -> H5互动 -> 预约体验 -> 电商购买 -> 后台监管。
- 技术路线：前端静态 MVP + Java Spring Boot 后端骨架 + MySQL 表结构。
